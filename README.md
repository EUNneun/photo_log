# Photo Route Lab

사진을 브라우저에서 직접 선택해 EXIF의 촬영시간과 GPS 위치를 추출하는 정적 웹 프로토타입입니다.

## 실행
`index.html`을 브라우저에서 열거나 정적 호스팅(Vercel, GitHub Pages 등)에 배포하면 됩니다.

## 현재 기능
- 다중 사진 선택 / 드래그앤드롭
- 촬영시간 추출
- GPS 위도/경도 추출
- 촬영시간 기준 정렬
- GPS/시간 보유 여부 표시
- CSV 저장
- 사진은 서버로 업로드하지 않고 브라우저에서 처리
